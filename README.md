# 🌌 Ashwoq 3D Portfolio

A fully interactive **3D portfolio experience** built with WebGL — combining design, animation, and performance optimization.

## 💻 Tech Stack

* **Three.js**
* **React Three Fiber**
* **@react-three/drei**
* **@react-three/postprocessing**
* **Postprocessing**
* **Blender**
* **GSAP**
* **detect-gpu**
* **PerformanceMonitor**
* **Vite**

---

## 🖱 Features

* 🎥 Scroll-driven cinematic camera
* 📱 Fully responsive (mobile portrait, landscape, tablets)
* 🔄 Adaptive camera FOV based on device
* 🎯 Device-aware animation behavior

---

## ⚙️ Performance & Optimization

* Dynamic performance scaling:

  * High-end GPUs → full bloom + high quality ✨
  * Lower-end devices → reduced effects for smoother performance 🧈

* Real-time performance adjustments using:

  * `detect-gpu`
  * `PerformanceMonitor`

---

## 🛠 Built From Scratch

* All 3D models created in **Blender**
* Custom UV mapping, texturing, and baking
* No external production assets used in this final version

## 🛠 Getting Started (Local Setup)

```bash
# clone the repo
git clone https://github.com/Ashwoq/Portfolio-3D.git

# go into project
cd Portfolio-3D

# install dependencies
npm install

# run dev server
npm run dev
```
