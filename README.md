A fully interactive **3D portfolio experience** built with WebGL — combining design, animation, and performance optimization.

## 💡 Inspiration

Inspired by Bilal Khan’s portfolio (https://mbilalkhan.com/),
with the goal of building everything **from scratch** — combining design, development, and performance.

---

## 💻 Tech Stack

- Three.js
- React Three Fiber
- Postprocessing
- Blender
- detect-gpu
- PerformanceMonitor
- GSAP

---

## 🖱 Features

- 🎥 Scroll-driven cinematic camera
- 📱 Fully responsive (mobile portrait, landscape, tablets)
- 🔄 Adaptive camera FOV based on device
- 🎯 Device-aware animation behavior

---

## ⚙️ Performance & Optimization

- Dynamic performance scaling:
  - High-end GPUs → full bloom + high quality ✨
  - Low-end devices → reduced effects for smoother performance 🧈

- Real-time performance adjustments using GPU detection + monitoring

---

## 🛠 Built From Scratch

- All 3D models created in **Blender**
- Custom UV mapping, texturing, and baking
- No external production assets used in this final version

---

## ⏳ Development

- ~3+ months of work
- 200+ hours (modeling, UV, baking, coding, debugging, optimization)
